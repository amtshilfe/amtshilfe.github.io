Einstellungen

Anzahl Monate

hier kann eingestellt werden, wie viele Monate gleichzeitig dargestellt werden.

Zeitraum (Startmonat)
Fristen
Wochentage

hier kann eingestellt werden, welche Wochentage bei der Berechnung der Fristen übersprungen werden (diese werden zur eingestellten Anzahl der Arbeitstage addiert).

Feiertage

hier kann eingestellt werden, welche Feiertage bei der Berechnung der Fristen übersprungen werden (diese werden zur eingestellten Anzahl der Arbeitstage addiert).

Fristverkürzung durch Feiertage

Fällt eine Frist auf einen hier ausgewählten Feiertag, wird sie auf den vorherigen Arbeitstag zurückdatiert. Es werden nur Feiertage angezeigt, die oben nicht zum Überspringen ausgewählt sind.

Datumsformat
Kopie-Einstellungen

hier kann eingestellt werden, ob Texte vor oder nach dem kopierten Text angehängt werden sollen. Bitte auch eventuelle Trennzeichen (z.B. Leerzeichen) vor oder nach dem jeweiligen Text beachten.

Einstellungen teilen

Erstellt einen Link, der die aktuellen, vom Standard abweichenden Einstellungen enthält. Dieser Link kann geteilt werden, um die gleichen Einstellungen auf einem anderen Gerät zu verwenden.
